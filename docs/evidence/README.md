# Visual evidence

Captures for the initial Super Agent Blog pull request, November 2026.

The repository contained only the initial `README.md` at `de346a7`, so there was no
prior blog interface to screenshot. The "before" capture is the blog's intended public
URL at that point, which had no published site. The "after" captures were taken from the
new static site served locally at `127.0.0.1:8765`.
